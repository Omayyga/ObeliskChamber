Create New Class - changes

1.0 (2026-11-15)
  First release. Everything below was built and tested in test builds
  ("stages") before it.
  - Create classes from the Class Change screen (left stick click), from a
    Base Class chosen by kind (Infantry, Magic, Armored, Cavalry, Fliers)
    and Class Tier; the game's own yes / no box asks first, then the new
    class opens.
  - Name and description typed on the game's keyboard.
  - Class Info: Class Tier, Movement, Class Type, Gender, Class Icon,
    Class Line.
  - Basic Stats, Class Bonus, Growth Rate, Growth Rate Bonus, Skill Exp
    Bonus.
  - Class Abilities 1-3, Master Ability.
  - Certification Exam: Primary and Secondary Skills, Pass Chance,
    barred characters.
  - Mounted classes: mounted Base Class required; generate and regenerate
    a dismounted class that follows the mounted one, with its own Class
    Bonus.
  - Look: body, material, outfit colours, map scale, accessories,
    footsteps, mount model, animations per weapon, casting model, effect
    and spell start; previewed on the unit.
  - Remove a class (asks first).
  - Safety: no job.txt in the download, job.txt.bak / asset.txt.bak kept
    and put back when needed, class keys never change.
  - The right stick no longer moves the creator's lists.
  - Quiet log by default; debug = true in job.ini for the full trace.
